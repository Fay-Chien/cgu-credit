# 長庚學分計算

貼上 iCGU「成績查詢」的歷年成績，算出長庚大學各類別（校訂共同必修、通識、系訂必修、選修）還差幾學分，並列出還沒修的系訂必修。

- 單一 HTML 檔，不需安裝，手機和電腦都能用。
- 成績資料只存在使用者自己的瀏覽器（localStorage），不會上傳。
- 支援百分制與等第制（A+～X）；判斷錯誤時可在「狀態」欄手動修改。
- 可選科系與入學年度，依學校公告的必選修科目表判斷必修、本系選修、外系選修與通識，並列出還沒修的必修。
- 科目表資料在 `programs.js`，目前已整理：人工智慧學系 112、114、115 學年入學。其他科系可先用「自訂畢業規定」。

本專案為學生自製工具，非長庚大學官方服務。
